# Security Policy

## Reporting a security issue

Please do not publish a working exploit for an unpatched issue in this repository.

Open a GitHub issue with a minimal reproduction that does not include passwords, API keys, private URLs, personal information, or other secrets.

## Scope

This project is a small WordPress hardening plugin. It reduces information disclosure and attack surface but is not intended to replace host security, updates, MFA, backups, rate limiting, or a WAF.
